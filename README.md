# caniwalkwithyou.com

The website for **can i walk with you?** - a home page, the privacy policy, the
terms and a support page. Served by GitHub Pages (Jekyll), at
https://caniwalkwithyou.com (the `CNAME` file).

- The contact email, the "last updated" date, and the few details still to
  fill in (legal name, minimum age, governing law) are in `_config.yml` - change
  them there and every page follows.
- The pages are `index.html`, `privacy.md`, `terms.md`, `support.md`, with one
  layout (`_layouts/default.html`) and one stylesheet (`assets/style.css`).
- No cookies, analytics or outside requests: the font (Courier Prime, SIL Open
  Font License - `assets/fonts/OFL.txt`) is served from this site.

The app links to `/privacy`, `/terms` and `/support` - keep those addresses.
